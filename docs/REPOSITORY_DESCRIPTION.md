# LogicaSophia — Repository Description

**Built by I2PS Engineering.**

**Suggested GitHub About text:** Standalone Linux AI engineering platform with original agent orchestration, auditable execution, PNG/PDF generation, optional image models and Lexia narration. Built by I2PS Engineering.

LogicaSophia is an I2PS-controlled engineering AI application with modular inference, policy-constrained tool execution, observable evidence, and a three-part Qt desktop interface: Assistant, Create and Results. The current release also includes genuine engineering document generation and optional locally configured image and speech integrations.
